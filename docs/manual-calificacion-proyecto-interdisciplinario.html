Calificación de proyectos interdisciplinarios

Flujo directo desde Configuración hasta Calificaciones, sin habilitar módulos adicionales ni crear una planificación interdisciplinaria.

Dirigido a: administradores, coordinadores y docentes
Versión: noviembre de 2026

1. Qué resuelve este flujo

La institución define cuánto vale el proyecto en el trimestre. Existe un solo proyecto interdisciplinario para el paralelo, pero cada asignatura conserva su propia nota. Si un profesor imparte varias materias participantes, puede registrar una vez y compartir la misma nota entre ellas.

1 · AdministraciónConfigura el porcentaje institucional.
2 · CalificacionesEl docente pulsa Proyecto 30 %.
3 · DocenteRegistra una nota individual por estudiante.
4 · ReversiónDesvincula una materia sin perder su nota.

Reglas esenciales

  • La nota se calcula como actividad de tipo Proyecto; el sistema la prepara automáticamente.
  • Solo se pueden compartir notas entre materias del mismo docente, proyecto, paralelo y período.
  • Cada materia participa con el porcentaje configurado para Proyecto.
  • Un período cerrado no permite crear vínculos ni modificar notas.

2. Administración: configurar el porcentaje

1
Ingresa con un usuario administrador y abre Configuración → Calificaciones.
2
Activa Habilitar Proyecto del período y asigna el porcentaje. Ejemplo: 30.
3
Comprueba que Actividades/Formativa, Examen y Proyecto sumen 100 % y guarda.
Porcentajes de la nota del período
Actividades / formativa70 %
Examen0 %
Proyecto30 %

Importante: cambiar estos porcentajes recalcula los resultados del período en todas las materias. Confirma la regla institucional antes de guardar.

3. Abrir el proyecto desde Calificaciones

1
El docente abre Calificaciones → Registrar notas.
2
Selecciona la materia y el trimestre.
3
Pulsa el botón Proyecto 30 %. El sistema crea o abre la columna institucional.
No se necesita: activar el menú Proyectos interdisciplinarios, crear insumos, agregar aportes ni aprobar una planificación.

4. Docente: registrar las notas

1
Al pulsar Proyecto 30 % aparece la lista de estudiantes.
2
Registra una nota por estudiante dentro de la escala institucional.
3
Pulsa Guardar notas.

Evaluar varios aspectos

En el selector se elige una sola opción: Proyecto del período. La tabla muestra cada aspecto como una columna. Si el docente necesita otro criterio, pulsa Nueva columna.

Las actividades del proyecto se promedian entre sí. Por ejemplo: 8 en Investigación, 9 en Producto final y 7 en Exposición producen una nota de proyecto de 8.

Una actividad que ya tiene notas no puede eliminarse. Primero deben retirarse sus notas para proteger el historial.

5. Usar la misma nota en otras materias

1
Abre Proyecto desde la materia que contiene las notas que deseas conservar.
2
En Usar esta misma nota en, marca las otras materias tuyas.
3
Pulsa Aplicar selección y confirma. Las notas de la materia de origen reemplazan las notas actuales de las materias marcadas.

6. Reversar una materia

Reversar no elimina notas. Solo termina la sincronización.

1
Selecciona cualquiera de las materias vinculadas.
2
Quita el check de la materia que debe calificarse de forma independiente.
3
Pulsa Aplicar selección.
4
Selecciona esa materia y modifica sus notas normalmente.

Qué se conserva: la materia desvinculada mantiene la última nota que tenía al momento de separarla. Los cambios futuros ya no se replican.

7. Controles y casos frecuentes

SituaciónComportamiento del sistema
El docente tiene una sola materiaRegistra la nota directamente; no se muestra una opción útil de replicación.
Participa una materia de otro profesorNo aparece entre las opciones para compartir.
La materia destino ya tiene notasSe solicita confirmación antes de reemplazarlas.
Se cierra el trimestreLas notas y los vínculos quedan en modo consulta.
El proyecto ya tiene notasNo se puede eliminar el proyecto ni retirar la materia, protegiendo el historial.
Se cambia una nota desde CalificacionesSe actualizan las demás materias que continúen vinculadas.

8. Lista de verificación administrativa

  • ☐ El porcentaje de Proyecto está configurado y los tres componentes suman 100 %.
  • ☐ El interruptor Proyecto del período está habilitado.
  • ☐ Los docentes seleccionaron el paralelo y trimestre correctos en Calificaciones.
  • ☐ Los docentes conocen cuál materia usarán como origen si compartirán notas.
  • ☐ Se revisaron las notas antes de cerrar el período.

Recomendación: si cada materia evalúa criterios distintos, no utilices la replicación. Registra una nota independiente en cada materia.
